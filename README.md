# Android-приложение «АРМ ЭТЛ — ООО «Сургут перевалка»» (исходный проект APK)

Нативное Android-приложение для работы на объектах с живой синхронизацией с вашим ноутбуком (поддерживает загрузку сканов PDF/фото, импорт Excel/CSV, скачивание `.docx` в папку «Загрузки» и ввод адреса ноутбука по Wi-Fi или Tailscale).

## Способ 1 — Получить готовый `.apk` за 2 минуты БЕЗ установки Android Studio (через GitHub)
1. Зайдите на [github.com](https://github.com) и создайте новый приватный репозиторий (например, `arm-etl-android`).
2. Загрузите в него все файлы из этого архива (включая скрытую папку `.github/workflows/build_apk.yml`).
3. Откройте вкладку **Actions** → дождитесь зелёной галочки (~2 минуты) → скачайте готовый файл **`ARM_ETL_Surgut_APK`** (`app-debug.apk`).
4. Перекиньте `app-debug.apk` на телефон и установите.

## Способ 2 — Сборка локально в Android Studio
1. Откройте папку проекта в **Android Studio**.
2. Дождитесь синхронизации Gradle и выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
3. Готовый `.apk` появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Первый запуск на телефоне
1. Запустите `start.bat` на ноутбуке и нажмите в шапке кнопку **«Телефон / Синхр.»**, чтобы увидеть IP-адрес (для работы по 4G с месторождения используйте бесплатный **Tailscale**).
2. Откройте приложение **«АРМ ЭТЛ»** на телефоне, введите адрес (например, `http://100.x.x.x:8080`) и нажмите **«Подключить»** — адрес запомнится навсегда.
